## 核心问题逐项复核

### P1-01 非 3D 资产详情身份错误：仍存在

- 路径/步骤：工作台 → 点击“新能源汽车 HMI 交互规范”。
- 期望：保留该 UI 资产的名称、ID、来源；不能预览时显示相应占位。
- 实际：标题变为“工业离心泵 · 装配模型（高精度）”。
- 根因：`src/App.jsx:502` 的 `onOpen` 将所有非 3D 资产替换为 `ASSETS[0]`。
- 证据：[详情截图](test-artifacts/reassessment-2026-10-09/wrong-detail.png)，[DOM 证据](test-artifacts/reassessment-2026-10-09/evidence.json) 的 `wrongDetail`。
- 建议/验收：统一详情容器，按类型切换预览；五类资产逐个打开后身份正确。无需为了修复此项引入真实 3D 引擎。

### P1-02 已保存筛选不恢复条件：仍存在

- 步骤：资产库 → UI 规范（2 项）→ 保存“复核-UI”→ 清除全部 → 点击“复核-UI”。
- 期望：恢复 UI 规范条件和 2 项结果。
- 实际：提示“已应用”，仍为全部 8 项。切换工作台再返回，已保存条目消失。
- 根因：Library 中 `savedFilters` 仅保存名称，应用按钮仅通知，没有条件快照。
- 证据：[截图](test-artifacts/reassessment-2026-10-09/saved-filter.png)；JSON `savedFilter`、`savedFilterAfterNavigation`。
- 建议/验收：保存并恢复类别、来源、成熟度、文件类型、标签、搜索、范围和排序；离开模块返回仍可应用。跨浏览器永久保存不是当前原型必须项。

### P1-03 上传展示图、规则与入库未贯通：仍存在，但并非整个上传功能都未实现

- 已有：本地文件、云盘、钉钉三种入口；展示图必填提示；导入队列；规则选择控件。
- 步骤：上传与导入 → 分别查看本地文件与云盘链接入口、展示图和导入规则。
- 期望：每项资产关联独立文件/分享链接、展示图、目标项目与成熟度；本地模拟完成后可在资产库和项目中找到。
- 实际：展示图只有地址文本框及示例按钮，没有对应的本地图选择入口；本地文件区提示“下方补充”但无补充区。规则的“应用”只提示成功。
- 代码证据：`src/App.jsx:352`、`:355` 创建的任务只保留名称/大小/类型/进度/状态，不保存链接、展示图或规则；任务不写入 `ASSETS`。`:354` 只校验 http(s) 前缀，不能视为真实分享链接可用性验证。
- 证据：[上传截图](test-artifacts/reassessment-2026-10-09/upload-preview.png)；JSON `localUpload`、`cloudUpload`。本轮未上传真实文件或执行真实入库。
- 建议/验收：做逐项待导入清单和会话内模拟入库；确认缺图阻止提交，成功项出现在正确项目中。无需真实上传服务、病毒检查或云盘连接。

### P1-04 查看者默认管理权限开启，角色状态共用：仍存在

- 步骤：项目与权限 → 角色与访问控制 → 查看者；关闭“管理角色与权限”，再选项目管理员。
- 期望：查看者默认禁止管理、邀请、编辑，各角色配置独立。
- 实际：查看者四项均为 checked=true；关闭管理权限后，项目管理员对应开关也关闭。
- 根因：`src/App.jsx:422` 的 `ProjectRolesPanel` 使用单个 `access` 对象（默认全部 true），未按角色关联。
- 证据：[查看者截图](test-artifacts/reassessment-2026-10-09/viewer-role.png)；JSON `viewer`、`adminAfterViewerChange`。
- 建议/验收：按项目 ID + 角色 ID 保存矩阵；切换角色、项目和模块均不串联。此为原型语义错误，不是生产越权证明。

### P1-05 客户端工具授权状态共用：仍存在

- 步骤：AI/MCP → 工具授权 → ChatGPT 关闭“搜索资产” → 切换 Codex。
- 期望：Codex 原权限保持开启。
- 实际：Codex 对应开关也关闭，授权计数从 4 变为 3。
- 根因：`src/App.jsx:464` 附近的 `McpCenter` 仅有单个 `permissions` 对象，没有按 clientId 存储。
- 证据：[截图](test-artifacts/reassessment-2026-10-09/shared-client-permissions.png)；JSON `mcpBefore`、`codexAfterChatgptChange`。
- 已有有效交互：客户端设置的默认授权范围可保存并立即回显，所以不能概括为“所有客户端设置都无效”。
- 建议/验收：逐客户端隔离授权、配置和连接状态；同一工具在各客户端可有不同状态。本轮没有变更真实 ChatGPT/Codex 授权。
