# Vigour Asset Hub·设计资产中枢（原型 v0.2.0）
  - 🏠 首页　—— 品牌着陆页
    - 品牌入口与快速导航　—— 展示旗舰 3D 资产，引导进入工作台 / 资产库
  - 📊 工作台
    - 精选资产
      - 团队推荐卡片　—— 精选 3 项资产，点击直达资产详情
    - 项目入口
      - 按参与范围 / 项目类型筛选　—— 范围×类型双维过滤，空态提供清除筛选
      - 点击项目 → 定位进入「项目与权限」　—— 以选中项目重挂载，标题与资产清单同步
  - 📚 资产库
    - 左侧筛选栏
      - 资产分类　—— 全部资产 / 3D 模型 / UI 规范 / 工作流 / Skill 卡 / 研究报告（带计数）
      - 资产来源
        - 多选筛选（含计数）　—— 全部来源 + 百度网盘 / 阿里云盘 / 钉钉链接 / Figma 等
        - 来源管理弹窗　—— 查看来源健康状态、按来源筛选；添加云盘 / 协作链接只登记元数据，不移动原文件
    - 工具栏
      - 快捷范围　—— 全部 / 我创建的 / 已收藏 / 待我评审（带计数）
      - 筛选下拉（14px·自适应）
        - 成熟度（单选，可取消回全部）　—— 已发布 / 已验证 / 试点 / 待评审 / 候选
        - 文件类型（多选 + 清除）
        - 标签（多选 + 清除，按热度取前 8）
      - 排序　—— 最近更新 / 名称 A–Z / 文件从大到小
      - 视图切换　—— 宫格（默认）/ 列表
    - 资产卡片操作
      - 收藏 / 批量选择与批量操作
      - 保存筛选 / 新建集合　—— 保存当前筛选快照，可恢复
  - 📦 资产详情
    - 3D 模型资产（真实 GLB）
      - 本地 GLB 实时渲染　—— Three.js：旋转 / 缩放 / 平移 / 网格地面
      - 结构树双向联动　—— 显隐真实控制 mesh.visible；选中聚焦高亮；点击网格反向定位；节点搜索无匹配显空
      - 贴图 / 版本 / 模型信息页
    - 通用资产详情
      - 来源追溯　—— 外链直达来源页面；本地文件保留 sourceFile；展示图可回看
      - 复制来源链接 / 模型地址 / 资产 ID
      - 预览类型诚实标注　—— 图片预览标「模拟」，与真实三维区分，不谎称可交互
  - 📤 上传与导入
    - 导入来源　—— 本地文件 / 云盘链接 / 钉钉链接
    - 导入任务队列
      - 进度与状态　—— 排队中 / 已暂停 / 已入库
      - 单任务操作：补图 / 编辑 / 移除　—— 缺展示图任务禁用「完成并登记」，可补图后入库或单独移除
      - 登记入库　—— 保留 externalUrl / sourceFile / 展示图；可提交评审
    - 格式与分类　—— 导入时选择归属项目、成熟度；分类可确认
  - 🗂 项目与权限
    - 项目列表　—— 搜索 / 分类筛选 / 新建项目（新项目即时进入列表）
    - 项目资产　—— 资产表格：勾选 / 排序 / 预览；「打开详情」真实跳转详情页
    - 成员　—— 邀请成员弹窗；角色按「项目 × 成员」隔离保存
    - 角色与访问控制
      - 角色模板　—— 项目管理员 / 编辑者 / 评审者 / 查看者
      - 项目设置　—— 名称 / 状态 / 默认访问范围，保存后可读回
  - 🤖 AI / MCP 接入中心
    - 客户端
      - Claude / Codex / 飞书 / WorkBuddy　—— 连接状态：已连接 / 需复核 / 未连接
      - 操作　—— 配置连接（本地模拟）/ 断开 / 客户端设置（名称、传输、授权范围）
    - 工具授权　—— 搜索资产 / 读取元数据 / 生成预览 / 请求下载 / 写入标签 / 创建项目引用
    - 调用记录　—— 按关键词与状态筛选（演示数据）
  - 📄 文档　—— 设计规范说明（目录级，含色彩 / 排版 / 组件）
  - ⚙️ 全局能力
    - 顶部搜索（⌘K 提示）
    - 通知 / 个人中心 / 团队标识
    - Toast 反馈
    - 边界说明　—— 仅本地原型：不连真实外部服务、不修改真实权限、不上传真实文件
